Air Pollution Detector Model using LED Indicators

Back

Objective

  • To detect the level of air pollution in the surroundings.
  • To create awareness about increasing air pollution.
  • To understand environmental science and electronic circuits.

Concepts Used

  • Air Quality
  • Environmental Pollution
  • Sensors and Electronics
  • LED Indicators
  • Basic Circuit Connections

Materials Required

  • MQ-135 Air Quality Sensor
  • Arduino UNO
  • 3 LEDs (Green, Yellow, Red)
  • 3 Resistors (220Ω)
  • Breadboard
  • Jumper wires
  • USB cable
  • Laptop with Arduino IDE

Steps to Make the Model

  1. Connect MQ-135 Sensor (VCC → 5V, GND → GND, A0 → Analog Pin A0).
  2. Connect Green LED → Pin 8, Yellow → Pin 9, Red → Pin 10.
  3. Attach resistors in series with LEDs.
  4. Upload Arduino code to read sensor values.
  5. Test using smoke or perfume spray.

How It Works

The MQ-135 sensor detects harmful gases like CO₂, smoke, ammonia, and benzene. It sends analog values to Arduino. Based on pollution level:

  • 🟢 Green LED → Clean Air
  • 🟡 Yellow LED → Moderate Pollution
  • 🔴 Red LED → High Pollution

When pollution increases, sensor output increases and the red LED glows.

Expected Result

  • Clean Air → Green LED glows.
  • Moderate Pollution → Yellow LED glows.
  • High Pollution → Red LED glows.

Conclusion

This project helps students understand air pollution and sensor technology. It creates environmental awareness and promotes using technology to monitor air quality.
